# IDRX

**IDRX is an Indonesian Rupiah stablecoin, pegged 1:1 to IDR.** It brings the rupiah on-chain so it can be used for digital payments, Web3 applications, and cross-border transactions with the speed and programmability of a blockchain token.

This GitHub organization hosts the engineering work behind IDRX: the token contracts, on-chain tooling, and the services that power [idrx.co](https://idrx.co).

## What IDRX does

- **Mint** — convert IDR into IDRX on a supported chain.
- **Redeem** — convert IDRX back into IDR to an Indonesian bank account.
- **Send & bridge** — move IDRX between wallets and across supported chains.
- **Integrate** — businesses can onboard users and process mint/redeem flows through a public API.

Supported chains and official contract addresses are always listed in the docs:
**https://docs.idrx.co/introduction/supported-chain-and-contract-address**

Only trust addresses published there or on [idrx.co](https://idrx.co).
